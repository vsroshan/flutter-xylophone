Xylophone 🎹

An interactive musical application built with Flutter and Dart.

This project demonstrates how mobile applications can respond to user interactions by playing audio, combining a simple interface with sound playback functionality.

📱 Overview

Xylophone recreates a digital xylophone using a series of interactive, color-coded buttons.

When a user taps a button, the application plays the corresponding musical note.

✨ Features

* Interactive musical buttons
* Audio playback triggered by user input
* Color-coded interface
* Simple, touch-friendly layout
* Sound asset integration

🛠️ Tech Stack

* Framework: Flutter
* Language: Dart
* Concepts: Event handling, asset management, and audio playback

📚 Key Learnings

* Responding to tap gestures
* Integrating audio assets
* Using Flutter packages for sound playback
* Connecting UI interactions to application behavior
* Creating a simple, touch-friendly interface

🚀 Getting Started

Prerequisites

* Flutter SDK
* Dart SDK
* A configured emulator or physical device

Installation

1. Clone the repository:

git clone https://github.com/vsroshan/flutter-xylophone.git

2. Navigate into the project directory:

cd flutter-xylophone

3. Install dependencies:

flutter pub get

4. Run the application:

flutter run
